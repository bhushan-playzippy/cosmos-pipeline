Hook clips you make with Veo in the Gemini app go here.
1. Run:  python main.py veo-prompts
2. For each prompt, open Gemini > Video (Veo), paste the prompt, ask for vertical 9:16.
3. Download the clip and save it here with the exact "SAVE AS" filename it printed.
The pipeline uses it as the first 2-4 seconds of that topic's video, then moves it to used/.
No clip for a topic? No problem, that video uses stock footage instead.
